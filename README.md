# 香火長明 (`pg-templeidle`)

香火累積、建築升級、離線收益的放置經營小品。

## 遊玩

- **點香**：點香爐添一炷香，立即獲得香火。
- **建築**：建造香爐自動聚香；升級鐘樓、正殿、長明燈強化產速、點香與離線效率。
- **離線**：進度與離線時間戳存於 `PG.kv`；回來可收取離線香火。
- **重修金身**：累積 500 香火且至少 5 座香爐後，可重置建築取得永久倍率。

純 HTML／CSS／JavaScript（無 build）。經 Playgrounds 畫布或 go 純玩執行。

## 開發

```bash
npx vitest run
```
